# Encriptador de Mensajes

Proyecto simple en Python para encriptar y desencriptar mensajes.

## ¿Cómo funciona?

Convierte cada letra en otro carácter usando una transformación básica.

## Uso

1. Ejecuta el archivo `encriptador.py`
2. Escribe un mensaje
3. Obtendrás:
   - Mensaje encriptado
   - Mensaje original recuperado

## Objetivo

Explorar ideas de privacidad en la comunicación digital y aprender uso de GitHub.
