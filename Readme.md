# 🔐 Love Code

Una herramienta web simple para encriptar y desencriptar mensajes usando una clave compartida.

## 🚀 Demo
https://zeajavier7-bot.github.io/ENCRIPTADOR-MENSAJES/

## 🧠 Cómo funciona
El mensaje se transforma carácter por carácter usando una clave, generando un texto encriptado que solo puede ser leído con la misma clave.

## 🛠️ Tecnologías
- HTML
- JavaScript

## 💡 Idea
Proyecto creado para explorar privacidad en comunicación digital y crear una herramienta simple para uso personal.
